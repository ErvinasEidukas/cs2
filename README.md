# CS2 Tools

A project dedicated to **Counter-Strike 2 (CS2)**, collecting useful information, tools, scripts, guides, and observations about the game in one place.

The goal is to make useful CS2 knowledge easier to find, understand, and use — both for myself and for other players.

## What you can find here

- Grenade lineups — Smoke, flash, molotov and HE grenade lineups.
- Debuts & setups — Useful positions, situations and techniques to practice.
- Scripts — Scripts and configurations for different situations and actions.
- Game mechanics — Explanations and information about how different CS2 mechanics work.
- Decision making — Different decisions and options that can be made during a match, depending on the situation.
- Collected information — Useful notes, findings, and knowledge collected from playing, testing, and researching the game.

## About the project

This project is a collection of experiences, findings, and information gathered over time and organized into a single place.

Instead of having useful information spread across different websites, videos, notes, and discussions, the goal is to keep it organized and easily accessible.

The project is intended to be useful for both **personal reference and other CS2 players** who want to quickly find information and use it in their games.

The content may include personal observations, community knowledge, testing, and information gathered from different sources. It is continuously updated as new information and discoveries are added.

## Website

The project is a **static website**. All required data is loaded with the page, so no backend or database is required.

The website is hosted using **GitHub Pages**.
